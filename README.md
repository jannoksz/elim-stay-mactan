# Elim Stay Mactan

A warm and responsive website for **Elim Stay Mactan**, a minimalist condo near Mactan-Cebu International Airport and popular beaches in Lapu-Lapu City, Cebu.

## 🌐 Live Website

Visit the application here:

<https://jannoksz.github.io/elim-stay-mactan/>

## ✨ What You Can Do

- 🏠 **Explore the condo** — View the bedroom, living room, dining area, kitchen, bathroom, and pool.
- 🖼️ **Browse the photo gallery** — Select a photo, use the previous and next buttons, or navigate with the left and right arrow keys.
- 🛏️ **Check the amenities** — Review included features such as air conditioning, Wi-Fi, TV, pool, gym, washing machine, and secure entry.
- 📍 **Find the location** — Open Primeworld District in Google Maps.
- 📝 **Review stay information** — Read check-in details, house rules, safety information, and cancellation details.
- 📅 **Choose a booking option**:
  - 🏡 Reserve through Airbnb
  - 📋 Send an inquiry using the Google Form
  - 📞 Call the property
  - 💬 Message Elim Stay Mactan on Facebook

## 🚀 Using the Website

1. Open the homepage.
2. Scroll or use the **Book now** link to move to the booking section.
3. Select **View photos** to open the photo gallery.
4. Use the gallery controls or your keyboard arrow keys to move between images.
5. Select **Show more** for house rules or safety information.
6. Select **Open in Google Maps** to see the condo location.
7. Choose an Airbnb listing, inquiry form, call, or Facebook option to contact the host.

## 🛏️ Guest Information

- **Maximum capacity:** 4 guests
- **Check-in:** After 2:00 PM
- **Check-out:** Before 11:00 AM
- **Arrival:** Self check-in with building staff
- **Required check-in items:** Fully completed guest registration, full payment, and 1 valid ID
- **Refundable deposit:** ₱500, returned after inspection

## 🧭 How to Run Locally

No package installation or build process is required.

### Option 1 — Open the file

Open `index.html` directly in a web browser.

### Option 2 — Use a local static server

From the project folder on Windows:

```powershell
python -m http.server 8000
```

Then visit:

<http://localhost:8000>

Stop the server with `Ctrl+C`.

## 📁 Project Files

- `index.html` — 🧱 Page content, sections, links, and dialogs
- `style.css` — 🎨 Design, responsive layout, animations, and dark-mode support
- `script.js` — ⚙️ Gallery, amenities, prices, dialogs, and interactive behavior
- `images/` — 📷 Condo photos, icons, and website illustrations
- `README.md` — 📖 Project and usage guide

## ✏️ Updating the Website

1. Edit the content in `index.html`.
2. Update the visual styles in `style.css`.
3. Change gallery images or app settings in `script.js`.
4. Place new image files inside `images/`.
5. Open `index.html` locally to check the changes.
6. Commit and push the updates to the `main` branch.

## 🌍 Publishing with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose the `main` branch and `/(root)` folder.
5. Save the settings and wait for deployment to finish.

GitHub Pages will publish the latest committed files automatically.
