# Elim Stay Mactan

A responsive, static website for Elim Stay Mactan, a minimalist condo in Lapu-Lapu City, Cebu. It includes a photo gallery, amenities, location details, house rules, and booking and contact links.

## Run locally

No build step or package installation is required. Open `index.html` in a browser, or serve this folder with any static web server.

## Publish with GitHub Pages

1. In the GitHub repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and the `/(root)` folder, then save.
4. Once deployment finishes, the site will be available at:

   <https://jannoksz.github.io/elim-stay-mactan/>

## Project files

- `index.html` — page content and structure
- `style.css` — layout, responsive styling, and animations
- `script.js` — photo gallery, amenities, and interactive behavior
- `images/` — website photos and illustrations

To update the live site, commit and push changes to the `main` branch. GitHub Pages will deploy the updated files.
